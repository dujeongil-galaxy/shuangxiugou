C 级 · 站长主观定级

本卡为站长人为干涉、直接判定的 C 级，不是按双休口径推导出来的结果

BOSS直聘 是招聘平台，不是用工单位，站内「双休率 / 平均下班时间」口径对它并不适用，因此本卡不套用该口径。站长据两点直接判 C：① 平台上虚假招聘、诈骗岗位、培训贷等套路长期泛滥，密度之高如同 PDD 上假货横行；② 平台规则双标——招聘方对求职者冷嘲热讽无人管，求职者被逼急回嘴却直接封号（详见下方「站长备注」亲历）。这是主观定级，特此向读者交代清楚，不伪装成客观数据。

平台口碑

虚假招聘、诈骗岗位投诉密集

为什么判 C 级（主观定级理由）

  • 虚假招聘与诈骗套路泛滥：平台上「高薪低门槛」岗位、培训贷、刷单、传销式招聘等投诉长期密集，求职者被骗入职、被诱导缴费的案例反复出现。站长给它的类比是——就像 PDD 上假货多一样，BOSS直聘 上假岗位多。这是「烂」的核心，也是定 C 的第一理由。
  • 平台规则双标：招聘方/HR 在沟通中对求职者冷嘲热讽、言语打压，平台基本不管；求职者一旦情绪失控回嘴，立刻封号，且换号因设备、身份关联被秒封（站长 2017 年亲历，见下）。规则只约束求职者一侧，不对称。
  • 简历意愿被无视：求职者在简历、个性签名里明确写了「不做销售」，依然被电销岗位反复轰炸推送，平台的岗位推荐与求职意愿严重脱节。
  • 不套用双休口径：本卡不是用工单位评级，双休率 / 下班时间字段标注「不适用」，C 级来自上述平台层面的主观判断，与站内其他企业的「双休判档」不是同一套推导。

站长备注：为什么我要人为干涉这一条

说明：下面这段是站长本人 2017 年的真实经历。我把它写出来，是因为如果只丢一个「C 级」而不交代原委，读者无从判断这是不是公报私仇、也无从事实里看见平台真正的毛病。我有错的部分，我认；但平台的问题，也确实存在。

2017 年，我在成都找工作。简历和个性签名都明明白白写了「不做销售」，结果推过来的全是电销岗——早上还要做早操、集体喊口号那种。我烦了，就跟一家公司的 HR 说，我不接受这种形式主义。

对方是个女 HR，当场阴阳怪气：「你本事大？你很牛逼？你不过是个毫无本事的求职者罢了，有什么资格提这些无理要求？」话越吵越多，她像极了我后来遇到的某个前女同事——自己不占理，但嘴上绝不服输，你说一句，她必定要顶回一句。

我最后没忍住，情绪失控，回了一句极其恶毒、涉及族裔的辱骂。

然后我就被封号了。换小号也不行——平台检测到同名、同一台手机，照样秒封。

我想说的不是「我骂人有理」——我越线了，这点我认，被封不冤。但真正的问题是双标：HR 当面甩脸子、冷嘲热讽，平台屁事没有；求职者被逼急了回一句，立刻封号。所以这一条我人为干涉、直接给 C：一半是因为平台长期假岗位泛滥（这是所有人都看得到的），一半是因为我亲身挨过它的双标（这是我个人能作证的）。两者我都摊开讲，读者自行判断权重。
