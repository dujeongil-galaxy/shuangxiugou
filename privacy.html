隐私政策

生效日期：2026-11-17 · 适用范围：本站全部页面（dujeongil-galaxy.github.io/shuangxiugou）

一句话版本：本站不设账号系统、不要求注册，你的投票与偏好只存在你自己的浏览器里。下文写清楚每一个例外。

1. 我们不收集什么

  • 没有注册/登录本站账号一说，没有用户数据库；
  • 不要求填写手机号、邮箱、真实姓名；
  • 当前未接入任何第三方统计 SDK（无站点级访问者画像）。

2. 存在你浏览器本地的数据（localStorage）

以下数据只保存在你的浏览器本地（localStorage / sessionStorage），不会上传到本站或任何服务器，清除浏览器数据即彻底删除：

  • 员工投票、打卡视角数据——刷新或清除即失效，站长侧不可见；
  • 搜索偏好、界面设置；
  • GitHub 登录状态键：sxg_github_logged_in、sxg_github_has_star、sxg_star_days（用途见下一条）。

3. GitHub 登录与 Star 判定

部分功能（如 AI 助手解锁）需要判定你是否给开源仓库点过 Star。点击「Login GitHub」走的是 GitHub 官方 OAuth 流程，本站只读取公开的 Star 状态用于解锁判断，不读取你的私有仓库、邮箱或关注列表。该过程同时适用 GitHub 的隐私政策。

4. AI 劳动法小助手（labor-ai.html）

你在 AI 对话里输入的问题文本，会经本站自行部署的服务端（Cloudflare Workers / 阿里云函数计算）转发给大模型 API 处理后返回。请注意：

  • 不要在对话里输入可识别你身份的信息（公司名+你的岗位组合也算）；
  • 对话内容用于生成回答，不用于向你推送广告；
  • 服务端日志由 Cloudflare / 阿里云按其各自的隐私政策处理。

5. 匿名邮箱

你可以通过匿名邮箱 tensi2026@choco.la 联系站长。邮件按普通电子邮件传输与存储，如需更高匿名性，建议配合一次性匿名邮箱服务（本站「匿名邮箱」入口弹窗已提示网络可达性注意事项）。

6. 广告与第三方 Cookie（含 Google AdSense）

本站为开源项目，可能通过广告维持运营（当前计划接入 Google AdSense；接入后本条款即适用）：

  • 第三方供应商（包括 Google）会使用 Cookie 向你投放广告，依据是你对本站及其他网站的访问记录；
  • Google 可借此展示基于你既往访问的广告；
  • 你可以在 Google 广告设置 关闭个性化广告，或在 www.aboutads.info 管理第三方供应商的广告 Cookie；
  • 本站自身不读取、不交叉比对广告 Cookie，也不向任何一方出售数据。

7. 数据不出售

本站不出售、不租借、不以广告画像为目的共享你的任何数据。本站的收入来源（赞助页、开源捐赠）均不依赖个人信息。

8. 数据保留与安全

本站没有服务器端个人资料库；GitHub Pages 的访问日志由 GitHub 按 GitHub 隐私政策 处理。全站通过 HTTPS 传输。

9. 儿童隐私

本站面向求职者与消费者，不面向 14 岁以下儿童，也不有意收集儿童个人信息。

10. 政策变更

本页更新即视为生效，页首「生效日期」随之更新；涉及广告接入等重大变化时会在首页公告栏提示。

11. 如何联系我们

对本政策或本站数据有任何疑问：GitHub Issues（公开、可追溯，推荐），或匿名邮箱 tensi2026@choco.la。更多方式见联系站长页。
