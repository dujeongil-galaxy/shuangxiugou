## 1. 项目定位与两站数据关系

**项目定位：本仓库是「双休购」主站**（线上应用，GitHub Pages 部署）。请与账号下另外两个双休购相关仓库区分：

- **shuangxiugou-guide**（[仓库](https://github.com/dujeongil-galaxy/shuangxiugou-guide)）→ 「双休购 2.0」公开资料站（[线上](https://dujeongil-galaxy.github.io/shuangxiugou-guide/)）的全量**纯静态备份**，收录 246 条企业/品牌线索（调研基准日 2026-09-09）。该仓库未做任何二次开发，无提交改动记录，内容与上游 [FuzzyLogic112/shuangxiugou-guide](https://github.com/FuzzyLogic112/shuangxiugou-guide) 保持一致。
- **shuangxiu-go-archive**（[仓库](https://github.com/dujeongil-galaxy/shuangxiu-go-archive)）→ 第三方网站「双休GO」(shuangxiu-go.cn) 的全量静态存档备份，与本主站数据无关联。

**两站数据的关系**：guide 站的 246 条是**研究线索**，按证据强度分为 A 公开确认 / B 媒体报道 / C 汇总候选 / 风险提示 / 作息待核验五档，其中大部分尚未取得一手证据。本主站只收录其中证据链完整、足以支撑评级结论的条目，其余线索保留在 guide 站作为待核实素材，因此两站收录数量不同是预期结果，并非数据冲突。

## 2. 主站的收录原则与判档口径

**主站的收录原则**（唯一标准，不因品牌知名度、规模或舆论热度而放宽）：

1. **客观中立**——只呈现可查证的公开信息，不掺杂立场好恶；
2. **不做情绪化表述**——描述作息与加班时以事实描述为准，避免掺入褒贬色彩或情绪化措辞；
3. **证据链不完善也照判不回避**——2026-10-31 站长纠正：U 级（待核实·不评级）恢复为合法档位，但**须附「证据缺失说明」（规则写死，见 README「U 级硬规则」）**，有证据可判的仍照判不回避。**判档只看月休天数、双休不限定必须落在周六日**：B 级 = 月休 6-8 天、A 级 = 月休 8 天以上、S 级 = A 级 + 真实双休率达标、C 级 = 月休不足 6 天或拒不披露。轮休制（做五休二、周休 2 天但休息日非固定周末，≈月休 8.6 天）属双休、判 A 级，不因休息日不固定扣档；主体为单休（如农行分行口径单休网点占 61%、主体月休 4-5 天）判 C 级——农行曾据此判 C 级，但 2026-11-04 站长线下复核确认其各网点每周关门一天（具体哪天不固定）+ 员工轮流双休（周休 2 天），已重新评级为 A 级（与工/建/中/成都行一致）。官方渠道被直接询问双休安排而拒不回答的（如淘宝闪购/饿了么），按无双休判 C 级；另站长 2026-11-01 线下走访某农行网点（未提前亮明身份）就与本站相关问题提问遭全面拒答，此项为站长一手实测（暗访式）佐证、印证官方渠道不主动披露双休，但不单独作为判档依据；数值字段无证据仍留空显示「—」，不用估算值、招聘方单方口径或论坛传言填充。企业公开披露休息制度后可重新核实。此口径同样适用于国有大企业、上市公司与知名消费品牌。

## 3. 架构说明：两套产物与卡片数据位置

⚠️ **架构说明（2026-10 修正）**：本仓库存在两套产物，请勿混淆——

- **线上实际部署**的是仓库根目录的**静态产物**：`index.html` + `assets/index-YthXZ9eP.js` + `assets/index-BgVofs0W.css` + `assets/*.logo`。GitHub Pages 直接发布仓库根目录，**不经过构建步骤**，推送即生效（约 60 秒）。
- `app/` 下的 Next.js 源码（`app/page.tsx` 等）**并未构建成线上页面**。`npm run build` 的产物也没有部署到 GitHub Pages。

**改数据前必看**：公司卡片数据分散在两处，改错位置不生效——

| 卡片类型 | 数据位置 |
|---|---|
| 53 张内置品牌卡（迪卡侬、瑞幸、星巴克、优衣库、喜茶、蜜雪冰城、霸王茶姬、格力、美的、胖东来、字节跳动、米哈游等） | `assets/index-YthXZ9eP.js` |
| 121 张自定义卡片（`customCardsConfig` 数组：肯德基、小米、兵立王、茶百道、赵一鸣、一点点、零食有鸣、工商银行、建设银行、中国银行、农业银行、成都银行、美宜佳、茉莉奶白、中国联通等） |根目录 `index.html` |

合计 173 张（53 内置 + 120 自定义）。另有 1 张「某代工烘焙食品」为**虚构对比黑榜卡**，不对外展示，故实际收录企业 172 家，与主页标题「共 172 家」及 `brand/` 详情页数量一致。

仓库根目录另有一份同名 `index-YthXZ9eP.js` 副本属**非部署文件**，改它不生效。

修改 `assets/` 下的 bundle 后，还需把 `index.html` 中的 `?v=N` 版本号加1 防浏览器缓存。
**仅改自定义卡（`index.html` 的 `customCardsConfig`）时 bundle 未变，不需要动 `?v`。**
