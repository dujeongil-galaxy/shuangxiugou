留言与参与准则

更新日期：2026-11-17 · 与联系站长、免责声明配套阅读

本站没有评论区，也没有账号系统。你不需要注册、登录或同意任何服务条款就能把全站读完。愿意开口的人，请走下面两条通道——它们都有痕迹，也都可以被追责。

1. 本站只有一个互动场所：GitHub

本站是纯静态页面，服务器上不存任何留言。所有公开讨论、纠错、投稿，实际上都发生在本站的 GitHub 仓库（Issues / 讨论区）里。也就是说，留言用的是你的 GitHub 身份，不是本站的匿名身份。

  • 公开通道：GitHub Issues（推荐，纠错处理最快，全过程全员可见）；
  • 匿名通道：站长匿名邮箱（适合不方便公开身份的情况，见联系站长）；
  • 本站的「员工投票」「申诉」表单，最终也都是跳到 GitHub Issue 里提交，没有第二条后端。

2. 这些话我们不予处理

下列内容会直接被关闭、隐藏或删除，不会进入任何审核讨论：

  1. 辱骂、人身攻击、地域或性别歧视，以及对他人身份、病情、家庭情况的恶意揣测；
  2. 人肉、挂人、公开他人真实姓名 / 手机号 / 住址 / 工号 / 内部截图等可识别信息；
  3. 同一诉求反复刷屏、复制粘贴同一段话、用小号扎堆带节奏；
  4. 与企业无关的时政、宗教、民族话题引流，以及任何违法内容；
  5. 商业推广、求职中介、贷款与灰产广告（公益广告位另有申请流程，见赞助页）。

关于刷屏与「带节奏」：本站没有账号系统，所以不存在「先警告三次、再按天数递减」的阶梯处罚。刷屏一旦被识别为组织行为，整串内容连同账号一起移交 GitHub 处理——因为一条恶意刷屏的成本极低，而维护者回应的成本极高。请把有限的口舌留给真实证据。

3. 严重违规：移交 GitHub 屏蔽或拉黑

GitHub 允许仓库维护者对特定账号执行屏蔽（Block）操作——被屏蔽的账号无法在本仓库的 Issues、讨论区里发言。对本仓库造成下列影响的账号，站长会直接使用这个功能：

  • 发布仇恨言论、人身威胁、骚扰他人，或反复违反第 2 条且无任何收敛；
  • 冒充企业方、冒充员工、冒充媒体，以伪造身份影响评级结论；
  • 向本站提交恶意链接、钓鱼页面、可执行文件，或试图诱导他人点击；
  • 批量刷 Issue、脚本灌水、用自动化手段干扰仓库正常协作。

被屏蔽不等于「本站的处罚」——它是 GitHub 平台功能，效力限于本仓库，不影响你在其他仓库的正常活动。若你认为屏蔽有误，仍可通过匿名邮箱说明情况，站长会复核一次。

4. 被屏蔽后仍想提交证据怎么办

  • 证据本身比说话的人重要：即使账号被屏蔽，真实、可查证的来源仍会受理；
  • 请改用匿名邮箱提交，附上原始链接与截图；
  • 核实后照常更正评级、在首页公示区留痕，不会因为提交者身份而区别对待证据。

5. 我们怎么对待写进来的人

本站的大多数证据来自陌生人的一手经验。任何人都可能记错、夸大或被当时的情绪影响——所以本站对匿名反馈一律降权处理、不单独定档（详见免责声明第 3 条）。同样地，对愿意认真写下的内容，我们尽量保留原话、标注出处，不替任何人加工立场。

6. 准则本身也会改

本页随站点一起开源，改动留痕在仓库提交记录里。如果某条规定让你觉得不合理，欢迎在 Issues 里直接指出——这条通道对所有人开放，也包括被屏蔽的人之外的每一位读者。
